# ใช้กับ ChatGPT

1. สร้าง Project แยกหนึ่งเรื่องต่อหนึ่งโปรเจกต์ ตั้งชื่อที่ค้นกลับง่าย
2. วาง `prompts/MASTER-PROMPT.md` เป็น Project instructions หรือข้อความแรก
3. แนบ `WORKFLOW.md`, `templates/PRODUCTION.md` และ `examples/jade-seal-48s.md`
4. ถ้ามีตัวเลือกความจำเฉพาะโปรเจกต์ ให้เลือกตั้งแต่สร้างเพื่อลดบริบทปนกัน วิธีและสิทธิ์ขึ้นกับบัญชี ดู [Projects in ChatGPT](https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt)
5. ส่งข้อความเริ่มงานใน README เมื่อเลือกเรื่องแล้วให้บอก `ใช้แบบที่ 2 ล็อกบทและตัวละคร แล้วสร้างชุดพรอมป์ต์ 6 ช็อต`

ถ้าแนบไฟล์ไม่ได้ ให้วาง master prompt ตามด้วยบรีฟเป็นข้อความ ใช้พรอมป์ต์ทีละช็อตเพื่อเลี่ยงคำตอบถูกตัด และเก็บผลลัพธ์ลงเอกสารของตัวเอง

## เมื่อมีเครื่องมือสร้างภาพ

ขอสร้างภาพอ้างอิงเดี่ยวทีละตัวละคร ตรวจรูปลักษณ์แล้วดาวน์โหลดภาพที่เลือก ใช้ไฟล์จริงใน Flow การเขียน prompt ภาพสำเร็จยังไม่ถือว่าสร้างภาพแล้ว

## เมื่อมีเครื่องมือควบคุมเบราว์เซอร์

แนบ `prompts/OPERATOR.md` และระบุโครงการ Flow ที่อนุญาต จำนวนครั้ง/งบ และสิ่งที่ให้ทำ ตรวจว่า agent มีเครื่องมือเข้าถึงหน้าจอจริงก่อนเริ่ม บัญชี ChatGPT ทั่วไปไม่ได้มีความสามารถเดียวกับสภาพแวดล้อมที่แสดงในคลิปทุกบัญชี

ถ้าไม่มี browser tools ให้ใช้ ChatGPT ทำบทและ prompt แล้วผู้ใช้คัดลอกไปวางใน Flow เอง ไม่ต้องติดตั้ง API server เพื่อใช้ repo นี้
