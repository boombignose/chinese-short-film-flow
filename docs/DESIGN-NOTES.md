# แนวทางจัดหน้าและที่มา

ตรวจตัวอย่าง repo วันที่ 21 กันยายน 2026 ใช้แนวทางการจัดข้อมูล ไม่คัดลอกภาพปก ข้อความ โค้ด หรือแบรนด์ของโครงการเหล่านี้

| Repo ที่ดู | สิ่งที่นำมาปรับใช้ |
|---|---|
| [prompts.chat](https://github.com/f/prompts.chat) | หัวเรื่องชัด ลิงก์เริ่มใช้ใกล้ด้านบน และคำอธิบายสั้นว่าชุด prompt ใช้ทำอะไร |
| [Superpowers](https://github.com/obra/superpowers) | แยกวิธีเริ่มต้นตามเครื่องมือ และแสดงลำดับ workflow |
| [Anthropic Skills](https://github.com/anthropics/skills) | มีตัวอย่างและเทมเพลตให้เปิดอ่าน พร้อมบอกขอบเขตการใช้งาน |

## งานภาพที่สร้างใหม่

ภาพ `assets/hero.png` สร้างด้วยเครื่องมือ imagegen ในงานนี้ ขนาด 2172 × 724 พิกเซล เป็นภาพแนวคิดสำหรับปก repo ไม่ใช่ภาพที่ตัดมาจากคลิปต้นฉบับหรือผลลัพธ์วิดีโอจาก Flow
