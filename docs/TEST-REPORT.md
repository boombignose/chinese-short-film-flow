## ชุดตรวจที่รันซ้ำได้

```sh
python3 scripts/check_repo.py
```

ตรวจลิงก์ภายในและไฟล์ภาพที่อ้างอิงใน Markdown/HTML, code fences, รูปแบบและขนาดภาพปก, storyboard S01–S06 รวม 48 วินาที และบทพูด/ผู้พูดที่ตรงกับพรอมป์ต์แต่ละช็อต

ทดสอบตัวตรวจด้วยสำเนาชั่วคราวที่จงใจทำลิงก์เสีย เปลี่ยนบทพูด และทำเวลา storyboard ขาดช่วง พบว่าตัวตรวจแจ้งไม่ผ่านทั้งสามกรณี และกลับมาผ่านหลังคืนข้อมูลเดิม

ชุดตรวจไม่ตรวจทุก URL ภายนอก ไม่ตรวจ semantic ของคำตอบ AI ไม่ตรวจภาพเคลื่อนไหว/เสียง และไม่รันการเจนที่ใช้เครดิต สถานะ CI ล่าสุดดูได้ที่ [GitHub Actions](https://github.com/boombignose/chinese-short-film-flow/actions/workflows/check.yml)

ใช้พรอมป์ต์ใน [quick-demo.md](../examples/quick-demo.md) แบบ Text-to-Video ผ่าน Video → Frames โดยไม่ใส่เฟรม เลือก Veo 3.1 Lite, 9:16, 720p, 8 วินาที, x1 หน้าตั้งค่าแสดง 10 เครดิตก่อนสร้าง ทดลองหนึ่งครั้ง ไม่มีการกด retry

ดาวน์โหลดขนาดดั้งเดิมจาก Flow แล้วบันทึกเป็น [assets/demo.mp4](../assets/demo.mp4) และแปลงเป็น [GIF พรีวิวเงียบ](../assets/demo.gif) ด้วย FFmpeg ภาพปก `assets/hero.png` เป็นงานแนวคิดจาก imagegen คนละแหล่งกับวิดีโอนี้

### ภาพที่ตรวจ

เปิดผลลัพธ์ใน Flow และตรวจเฟรมที่ประมาณ 0.5, 4 และ 7 วินาที:

- มีตัวละครผู้ใหญ่สองคนในหอเอกสาร ผู้หญิงซ้าย ผู้ชายขวา ตามทิศทางที่ขอ
- ผู้หญิงถือหยกอยู่ในมือขวาในเฟรมที่ตรวจ ไม่พบคนที่สามหรือซับติดภาพในเฟรมเหล่านั้น
- **ไม่ตรงบรีฟ:** ขอหยกรูปวงกลม แต่ได้ทรงยาวตกแต่งลวดลาย จึงไม่ให้ผ่านด้านอุปกรณ์
- ปลายคลิปผู้ชายอ้าปาก แม้สั่งให้ปิดปาก การอ้าปากอย่างเดียวไม่ยืนยันว่าเขาพูด แต่ยังไม่ตรงข้อกำหนดภาพ
- ไม่อ้างว่าตรวจทุกเฟรมหรือพิสูจน์ความต่อเนื่องข้ามช็อตแล้ว เพราะเป็นช็อตเดียวโดยไม่มี reference

### เสียง

บทที่ขอ: `ตรานี้ บอกว่าท่านตายไปแล้ว`

ทดลองถอดเสียงด้วย faster-whisper รุ่น small ที่มีอยู่ในเครื่อง ได้:

```text
0.00–4.56: ตรานนี้บอกว่า ท่านตายไปแล้วเช่นกัน
```

ผลถอดเสียงบ่งชี้ว่าอาจมีคำเพิ่มท้ายประโยค แต่เป็น ASR และระหว่างรันมี numerical warnings จึงไม่ใช้เป็นหลักฐานยืนยันคำพูดหรือผู้พูดเพียงอย่างเดียว สถานะเสียงคือ **NEEDS_HUMAN_REVIEW**: ต้องฟัง MP4 เทียบกับบทก่อนเผยแพร่เป็นงาน final

### สิ่งที่จะปรับในการทดลองถัดไป

1. แนบ reference ของตราหยกวงกลมจริงและเฟรมเริ่มต้นที่ตรวจแล้ว
2. ใช้เฟรมใกล้เฉพาะผู้พูด ลดตัวละครที่อาจขยับปากในช็อตสนทนา
3. หากเสียงยังเพิ่มคำ ให้แยกพากย์เสียงที่อนุญาต แล้วตรวจ lip sync และเสียงเดิม
