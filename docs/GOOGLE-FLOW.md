# ใช้ Google Flow กับชุดพรอมป์ต์นี้

ตรวจคู่มือ Google วันที่ 21 กันยายน 2026 เมนูจริงอาจต่างตามบัญชี ภูมิภาค และรุ่น UI ให้ยึดความสามารถที่ปรากฏในบัญชีของคุณ

## เตรียมก่อนสร้าง

เปิด [Google Flow](https://labs.google/fx/tools/flow) และสร้างโปรเจกต์สำหรับเรื่องนี้ เตรียมภาพอ้างอิงที่เลือกแล้ว บทล็อก และรายการช็อต ตรวจเครดิตและต้นทุนที่หน้าสร้างก่อนกด Generate

## สร้างภาพ

เลือกงานประเภท Image วางพรอมป์ต์ reference จากตัวอย่าง สร้างภาพเดี่ยวของแต่ละคนก่อน แล้วใช้ภาพที่เลือกช่วยสร้างเฟรมเปิด 9:16 เก็บชื่อไฟล์ให้ตรง ID ไม่ใช้เพียงข้อความ “เหมือนเดิม” โดยไม่มี reference แนบ

Google ระบุว่า Flow สร้างและแก้ไขภาพภายในโปรเจกต์ได้ ดู [คู่มือภาพ](https://support.google.com/flow/answer/16729550?hl=en)

## สร้างวิดีโอทีละช็อต

1. เลือก Video และโหมดที่ตรงงาน: **Frames** เพื่อเริ่มจากเฟรมที่จัดองค์ประกอบแล้ว หรือ **Ingredients** เพื่ออ้างอิงตัวละคร/วัตถุ
2. แนบภาพอ้างอิงจริงตามชื่อที่พรอมป์ต์อ้างถึง ถ้า UI มีการอ้าง asset ด้วย `@` ให้เลือก asset ที่มีอยู่ในโปรเจกต์
3. วางพรอมป์ต์ของช็อตเดียว ตรวจรายละเอียดตัวละคร การเคลื่อนไหว กล้อง และบทพูด
4. ตั้ง 9:16 เลือกโมเดลที่รองรับโหมดนั้น ตรวจระยะเวลาและจำนวนผลลัพธ์ เริ่มหนึ่งผลลัพธ์เพื่อตรวจคุณภาพ
5. กด Generate ภายในขอบเขตเครดิตที่อนุญาต แล้วเปิดผลลัพธ์เพื่อดูและฟัง บันทึก take ที่เลือก

ขั้นตอนโหมดภาพอ้างอิงและเฟรมอิงจาก [คู่มือสร้างวิดีโอของ Google](https://support.google.com/flow/answer/16353334?hl=en) ข้อความ audio ในพรอมป์ต์เป็นคำสั่งเชิงเนื้อหา ไม่ใช่การรับประกันว่าจะพูดตรงบท

## ระยะเวลาและการเปลี่ยนโมเดล

ตาม [ตารางความสามารถของ Google](https://support.google.com/flow/answer/16352836?hl=en) ที่ตรวจวันนี้ Veo 3.1 Fast รองรับ Text/Frames แบบ 4, 6, 8 วินาที และ Ingredients แบบ 8 วินาที รองรับทั้งสองอัตราส่วน ตรวจตารางและ UI อีกครั้งก่อนใช้จริง

ตัวอย่างใน repo จึงวาง 6 ช็อต ช็อตละ 8 วินาทีเป็นฐาน หากเลือกโมเดลอื่นและมีระยะเวลาต่างออกไป ให้สร้างตามที่รองรับแล้วตัดต่อใหม่ บันทึกความยาวจริง แทนการอ้างว่า prompt จะบังคับความยาวได้แน่นอน

ถ้าเกิด error: อ่านข้อความ ตรวจเครดิตและสถานะงานเดิม ลดให้เหลือช็อตเดียว แล้วเปลี่ยนตัวแปรทีละอย่าง การเปลี่ยนโมเดลต้องตรวจโหมดที่รองรับและค่าใช้จ่ายใหม่ ไม่สรุปว่าโมเดลใดเสียจากคลิปตัวอย่างเดียว

## รวมคลิป

ใช้ Scenebuilder เมื่อมีใน UI เพื่อเรียง ตัด และพรีวิว หรือส่งออกแต่ละคลิปไปโปรแกรมตัดต่อที่ใช้อยู่ ตรวจไฟล์ส่งออกจริงตาม WORKFLOW ก่อนส่งมอบ ดู [คู่มือการตัดต่อและสร้างฉาก](https://support.google.com/flow/answer/16935718)

repo นี้ไม่มี Google Flow API integration, ไม่มี Google Cloud Workflows YAML และไม่มีสคริปต์ควบคุมเบราว์เซอร์ที่ติดตั้งมาให้ การทำงานผ่าน agent ต้องใช้เครื่องมือที่มีจริงในโปรแกรมของผู้ใช้
