## วิเคราะห์วิธีเล่าเรื่อง

ตัวอย่างใช้ความลับเรื่องเจ้าสาวและการช่วยแม่เป็นแรงขับ เปิดด้วยคำถามที่บังคับให้ตัวละครเลือก ตามด้วยข้อมูลใหม่และความร่วมมือที่ทำให้เรื่องไปต่อได้ ลักษณะนี้เหมาะกับตอนสั้นเพราะเริ่มที่ความขัดแย้งทันที

ภาพที่ตรวจแสดงเครื่องแต่งกายจีนย้อนยุค ฉากภายใน และระยะใกล้/กลาง ทำให้คนดูติดตามสีหน้าและความสัมพันธ์ของคู่ตัวละครบนจอแนวตั้งได้ การใช้ reference ช่วยคงรูปลักษณ์ แต่การตรวจภาพไม่สามารถยืนยันว่าใบหน้าเหมือนกันทุกเฟรมได้

## ข้อจำกัดที่ต้องไม่มองข้าม

1. **แผนกับผลที่โชว์ต่างกัน:** มีการกล่าวถึงแผน 48 วินาที แต่ตัวอย่างท้ายคลิปประมาณ 22 วินาที จึงไม่อ้างว่าคลิปยืนยันการสร้างตอน 48 วินาทีครบสำเร็จ
2. **การลองใหม่ไม่ใช่หลักประกัน:** คลิปมี error หลายครั้งและยังระบุสาเหตุไม่ได้ repo จึงเพิ่มเพดานทดลองและบันทึก take แทนการปล่อยรันไม่จำกัด
3. **เสียงคือจุดเสี่ยงที่พบจริง:** มีคำวิจารณ์เรื่องผู้พูดสลับบท repo จึงแนะนำหนึ่งผู้พูดต่อช็อตและตรวจไฟล์จริง
4. **ไม่มีตัวเลขต้นทุนที่ตรวจครบ:** ไม่คำนวณราคา จำนวนเครดิต หรืออัตราสำเร็จจากคลิปนี้
5. **การโพสต์ไม่ได้ตรวจซ้ำ:** ไม่ได้เปิดโพสต์ Facebook/TikTok ปลายทางเพื่อยืนยันสถานะปัจจุบัน
6. **Claude เป็นส่วนต่อยอด:** คลิปนี้สาธิต ChatGPT แนวทาง Claude ใน repo เป็นการดัดแปลง workflow โดยผู้จัดทำ ไม่ใช่สิ่งที่คลิปทดลองให้เห็น

## สิ่งที่ repo เพิ่มจากการวิเคราะห์

- บรีฟและ character bible ที่ใช้ร่วมกันได้ทั้ง ChatGPT และ Claude
- บทพูดตรงตัว ผู้พูดที่ระบุชัด และ continuity state ของอุปกรณ์
- ทดสอบหนึ่งช็อตก่อน พร้อมขั้นแก้ปัญหาและเพดานการทดลอง
- แยกเวลาตัดต่อเป้าหมายจากระยะเวลาที่โมเดลรองรับ
- เกณฑ์ตรวจภาพ/เสียง การส่งมอบไฟล์ และการยืนยันโพสต์จริง
- ตัวอย่างเรื่องใหม่ “ตราหยกใต้โคมแดง” เพื่อฝึก workflow โดยไม่คัดลอกเรื่องเดิม

เอกสารนี้เป็นการสรุปและวิจารณ์ต้นทาง ไม่แจกคำบรรยายเต็ม ภาพหน้าจอ หรือวิดีโอต้นฉบับ
