# Chinese Short Film Production Assistant

Read WORKFLOW.md and prompts/MASTER-PROMPT.md before production work. Use docs/GOOGLE-FLOW.md for browser steps and templates/PRODUCTION.md for each new film. Respond in Thai unless the user requests otherwise.

This repository contains instructions and examples, not a working media automation service. Do not scaffold an app, install dependencies, spend generation credits, or publish content unless that action is within the user's request and authorization. Preserve existing authorization; do not ask again unnecessarily.

Check actual tool capabilities. An agent without browser or media tools must produce copy-ready prompts and manual steps. Never claim that a generated plan is a rendered or verified video. Preserve approved references and dialogue; repair individual shots. See prompts/REPAIR.md.

Keep new production assets in a separate workspace; never overwrite the original example. Never commit credentials or downloaded source video. Do not claim QC passed without watching/listening to actual output. Use NEEDS_HUMAN_REVIEW when appropriate.
