# คำสั่งสำหรับ agent ที่ทำงานในเบราว์เซอร์ได้

ใช้ร่วมกับ MASTER-PROMPT และ production pack ที่เลือกแล้ว คำสั่งนี้ไม่ติดตั้งเครื่องมือหรือให้สิทธิ์ใหม่

```text
อ่านบรีฟ บท character bible และพรอมป์ต์ที่แนบ รักษารายละเอียดที่ล็อกไว้

ก่อนทำงาน ตรวจว่าเครื่องมือของคุณเข้าถึง Google Flow ในเบราว์เซอร์ได้จริง
ระบุบัญชีและชื่อโปรเจกต์ที่จะใช้จากหน้าเว็บ ห้ามเดาว่าบัญชีที่เปิดอยู่เป็นปลายทางที่ถูกต้อง
ถ้าไม่มีเครื่องมือควบคุม ให้ส่งชุดพรอมป์ต์และขั้นตอนคัดลอกแทน

ใช้เฉพาะโปรเจกต์และงบที่ฉันระบุในข้อความประกอบ หากยังขาดงบ ให้จัดชุดงานและรายการตั้งค่าที่ตรวจได้ก่อนถาม
ตรวจเครดิต โมเดล โหมด อัตราส่วน ระยะเวลา และจำนวนผลลัพธ์ที่ UI ก่อน Generate
สร้างช็อตทดลองหนึ่งช็อตก่อน อย่าสร้างทุกช็อตพร้อมกัน
แนบ reference ที่เลือกจริง ตรวจว่าอัปโหลดสำเร็จและถูกเลือกอยู่

หลัง Generate ตรวจสถานะเดิมก่อนเริ่มซ้ำ เมื่อได้ผลเปิดวิดีโอเพื่อตรวจหน้า ชุด การกระทำ และเสียงเทียบกับบท
ถ้าไม่สามารถฟังเสียงได้ ให้เก็บเป็น NEEDS_HUMAN_REVIEW อย่าสรุปว่าผ่าน
เก็บ take ที่ผ่านและ prompt เวอร์ชันที่ใช้ งานที่ยังรันอยู่ห้ามส่งซ้ำ
ลองรวมไม่เกิน 3 ครั้งต่อช็อตหรือจนงบที่ฉันระบุหมด แล้วแต่ถึงก่อน
หากต้องเปลี่ยนโมเดล ตรวจการรองรับโหมดและเครดิตใหม่ภายในงบเดิม
ไม่เปลี่ยนเรื่องหรือตัวละครเพื่อแก้ปัญหาทางเทคนิค

ประกอบช็อต เพิ่มซับตามบท และตรวจไฟล์ส่งออกตั้งแต่ต้นจนจบ
ส่งไฟล์จริงพร้อมชื่อ ความยาว ความละเอียด take list และ QC log
ถ้าได้เพียงลิงก์พรีวิว ให้รายงานว่าเป็นพรีวิว ไม่เรียกว่าไฟล์ final
ทำแคปชั่นเป็นร่างก่อน ยกเว้นฉันมีคำสั่งเผยแพร่ชัดเจนอยู่แล้ว
เมื่อได้รับคำสั่งโพสต์ ให้ตรวจบัญชีและโพสต์เดิมก่อนส่ง เพื่อไม่โพสต์ซ้ำ แล้วเปิดโพสต์จริงเพื่อยืนยัน URL
```

ข้อความประกอบตัวอย่าง: `ใช้โปรเจกต์ Flow ชื่อ Jade Seal EP01 สร้างช็อต S01 เท่านั้น หนึ่งผลลัพธ์ต่อครั้ง รวมไม่เกิน 2 ครั้ง และไม่เกินงบเครดิตที่ฉันระบุในบรีฟ ยังไม่โพสต์` — ต้องกรอกงบจริงก่อนเริ่มใช้เครดิต
