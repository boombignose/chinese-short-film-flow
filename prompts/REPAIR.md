# แก้เฉพาะช็อตที่ไม่ผ่าน

แนบ prompt เดิม reference และอธิบายสิ่งที่เห็น/ได้ยินจริง ไม่ให้ AI เดาจากคำว่า “ไม่ดี” อย่างเดียว

## เสียงผิดคน / บทหลุด

```text
ช็อตที่ต้องแก้: [ID]
ผู้พูดที่ถูกต้อง: [ID และชื่อ]
บทที่ต้องพูดตรงตัว: [บท]
ผลที่ได้จริง: [คำที่ผิด/คนที่พูดผิด/เวลาในคลิป]
คงหน้า ชุด ฉาก กล้อง และการกระทำจากเวอร์ชันที่เลือก
ปรับให้มีผู้พูดหนึ่งคน อีกคนปิดปากและแสดงปฏิกิริยาเท่านั้น
ไม่เติมบท ไม่แปลภาษา ไม่เพิ่มผู้บรรยาย ไม่พูดพร้อมกัน
ส่งพรอมป์ต์แก้แบบครบในตัวและ checklist เทียบเสียง ไม่สร้างซ้ำเองหากยังไม่มีสิทธิ์ใช้เครดิต
```

หากยังผิดหลังจำนวนครั้งที่กำหนด ให้เสนอแยกช็อตหรือพากย์เสียงแยกที่ได้รับอนุญาตพร้อมผลกระทบต่อการตัดต่อ ไม่อ้างว่า negative prompt จะแก้ได้แน่นอน

## หน้า / ชุด / อุปกรณ์เปลี่ยน

```text
ช็อต [ID] มีปัญหา [ระบุสิ่งที่เปลี่ยน]
ภาพอ้างอิงที่ถูกต้องคือ [ไฟล์ที่แนบจริง]
คืนรายละเอียด [ใบหน้า/ผม/สีชุด/เครื่องประดับ/มือที่ถือของ] ให้ตรง character bible
รักษาการกระทำ บทพูด และความยาวเป้าหมายเดิม
ลดตัวแปรการเคลื่อนไหวที่ไม่จำเป็นและระบุสถานะอุปกรณ์ต้น–ท้ายช็อต
ส่งพรอมป์ต์แก้ช็อตนี้เท่านั้น พร้อมรายการ reference ที่ต้องเลือกใน Flow
```

## Error / งานไม่ออก

```text
ช็อต [ID], โมเดล [ชื่อที่เห็น], โหมด [Frames/Ingredients/Text], ระยะเวลา [ค่าจริง]
ข้อความ error: [ตามหน้าเว็บ]
จำนวนครั้งที่ลองแล้ว [จำนวนรวม], งบที่เหลือ [ค่าที่ตรวจได้หรือไม่ทราบ]
ตรวจว่างานเดิมยังรันหรือมีผลลัพธ์แล้วก่อนส่งซ้ำ
เสนอการทดลองครั้งถัดไปโดยเปลี่ยนตัวแปรเดียว และเก็บบท/ตัวละครไว้
ถ้าไม่รู้สาเหตุให้บอกว่าไม่ทราบ ไม่อ้างว่าระบบล่มหรือเครดิตคืนโดยไม่มีหลักฐาน
```
